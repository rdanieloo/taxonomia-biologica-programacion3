# taxonomia-biologica-programacion3
Proyecto Final Programacion 3 - Sistema de Taxonomia Biologica

## 🐳 Instrucciones de Docker (DevOps)
- **Modo Memoria Aislado:** `docker compose --profile memory up --build`
- **Modo Completo (Postgres + Neo4j):** `docker compose --profile full up --build`
- **Detener Contenedores:** `docker compose down`
